# Tov Hayom: אב-טיפוס של המסך הראשי

אב-טיפוס של צד הלקוח בלבד, לפי course-stack.md ו-ARCHITECTURE.md: HTML, CSS ו-JavaScript, בלי כלי בנייה, בלי שרת ובלי מפתחות.
כל הנתונים הם נתוני דמה להמחשה בלבד (`data/mock-data.js`).

## איך פותחים
- במחשב: לחיצה כפולה על `index.html`. נפתח בדפדפן, בלי התקנה.
- ב-GitHub Pages: מעלים את התיקייה לשורש של ריפו ציבורי, ומפעילים Pages על ענף main.

## מה יש
- כרטיס "טיול היום": שם, קטגוריה ואזור, תג אימות, "נבדק לאחרונה", משפט הסבר ו"לפרטים".
- מדף "מקומות נוספים" שנגלל מימין לשמאל, עם נקודות מיקום.
- פרטי מקום: שעות פתיחה, דירוג (ערך דמה), אזור, ו"אין לנו מידע" כשחסר נתון.
- הסבר לתג: ארבע רמות האימות.
- מצבים: רגיל, אין המלצה, טעינה, שגיאה. מחליפים בקישורים בתחתית הדף, או ב-`index.html?state=empty` / `error` / `loading`.

## הכללים שהאב-טיפוס מדגים
- מקום חסום, לא מאומת או לא בטוח לא מוצג (בנתונים: אולם מופעים לדוגמה חסום, שמורת נחל לדוגמה לא מאומתת, אתר מורשת לדוגמה לא בטוח).
- כלל 90 היום: פארק אשדוד ים שמור כ"מאומת" אבל נבדק לפני יותר מ-90 יום, ולכן מוצג כ"נבדק".
- מיון המדף: "מאומת" קודם, אחריו "נבדק", והבדיקה החדשה ראשונה.

## מבנה
```
index.html
css/style.css
js/mock-api.js   מחליף את api/trip.js (action=home, action=rating). רק הוא יתחלף כשיהיה שרת
js/lists.js      תוויות בעברית ותאריך dd.mm.yyyy
js/badge.js      תג האימות
js/card.js       הכרטיס המשותף (today, shelf)
js/main.js       המסך הראשי, המדף, החלונות והמצבים
data/mock-data.js  קטגוריות, אזורים, רמות, 15 מקומות וכרטיס היום (דמה)
img/icons/       אייקון לכל קטגוריה, לאריח כשאין תמונה
img/places/      תמונות ברישיון חופשי מ-Wikimedia Commons, מוקטנות לרוחב 1,600px
```

## הנחות
- הנתונים ב-`mock-data.js` ולא בקבצי JSON, כדי שלחיצה כפולה תעבוד בלי שרת. המבנה זהה ל-JSON שב-ARCHITECTURE.md.
- האזורים לפי ARCHITECTURE.md: אזור אחד לאשדוד, ואזור לכל יישוב מחוץ לה (יבנה, גדרה, ניצנים, אשקלון, באר שבע). היישובים נבחרו לאב-טיפוס בלבד. שמות עם "לדוגמה" הם מקומות בדויים.
- התמונות של המקומות האמיתיים הן מ-Wikimedia Commons, ברישיון חופשי (CC0, CC BY או CC BY-SA). הקרדיט לכל צלם מופיע בתחתית הדף, תחת "קרדיט לתמונות". למקומות בדויים ולמקום בלי תמונה מוצג אריח הקטגוריה.
